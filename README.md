# Atividade - POO Básica - Produto
Base para a atividade de código - Classe `Produto`.

## Enunciado

Iremos desenvolver um sistema simples de vendas e faturamento para um pequeno comércio. Como primeiro passo, precisamos representar os **produtos** que serão vendidos.

Um `produto` tem uma **descrição** e um **preço de custo**. Seu **preço de venda** será dado pela adição da **margem de lucro** ao seu preço de custo.  A margem de lucro é definida pelo vendedor e pode estar **entre 10 a 50% do preço de custo**. A **nota de venda** do produto deve mostrar sua descrição e preço de venda com formatação adequada.
